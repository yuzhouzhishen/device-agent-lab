冻结日期：2026-08-07。

DeviceOps 版本：`1.3.0`。

## 范围

验证对象是一台本人明确授权操作的测试设备，通过公司已有 XDP MCP 的
Streamable HTTP 接口访问。本文和源码均不记录 PSN、Token、完整 URL、SSID、
BSSID、MAC 或原始 PD 身份字段。

   Planner 在模型不可用时提供确定性降级。
2. 顶层意图路由能够区分业务聊天、知识问答、设备查询/诊断/控制、信息澄清和
   范围外请求；只有设备分支会访问 XDP MCP。
3. LangGraph 完成整机查询、指定端口查询、整机诊断和端口诊断。
4. XDP MCP 工具发现和以下证据调用成功：
   - 设备事实与端口列表
   - 端口实时状态
   - 充电状态
   - PD 协商状态
   - 温度/性能模式
5. DeviceOps 调用独立 Firmware Knowledge Agent，返回文档建议与来源引用，
   无降级标记。
6. Web 控制台显示实时遥测、知识建议、引用、LangGraph Trace、逐节点耗时和
   Planner token。
7. “你是谁”“今天天气怎么样”“打开端口”分别验证了聊天、范围外和澄清
   分支，均未误触发设备工具；澄清结果不再显示成设备故障。
8. 已验证知识库内问题能够返回引用，知识库无证据时明确拒答，不编造协议结论。
9. 真实设备只读查询后继续追问“为什么”，系统能够引用上一轮的端口、模式、
   连接、功率和协议证据解释结果。
10. 真实关闭目标端口，MCP 控制成功；增加延迟轮询后，操作后状态验证为关闭。
11. 随后真实重新开启目标端口，操作后状态先进入待机/连接状态，数秒后的只读查询
   恢复为实际充电并返回电压、电流和功率，设备已恢复。
12. 自动控制模式将规划和自动 resume 两段指标合并为一条完整执行记录。
13. 本地 Python 服务与 macOS OrbStack Compose 容器链路都完成：

```text
DeviceOps -> RAG -> Ollama -> XDP MCP -> 授权真实设备
```

14. 桌面与 390 px 移动视口完成浏览器 QA，无横向溢出、控件遮挡或前端错误。

## 暴露并解决的问题

### 1. 设备状态不是强一致

第一次控制后立即读取时，MCP 已返回成功但遥测仍是旧值。说明控制命令经过远端
服务、设备通信和固件状态更新后需要收敛时间。

处理：`verify_control` 改为延迟并最多轮询指定次数，最终仍不符合时返回
`mismatch`，不把工具成功包装成状态已改变。

### 2. PD 请求能力与实际协商需要区分

端口可能正在正常输出，但请求档位和协商结果存在能力差异。整机与端口诊断把
`request_capability_mismatch` 纳入可疑证据，不再只看“是否有功率”。

### 3. RAG 查询不能硬编码端口编号

业务文档写的是通用端口故障规则，直接把“3号端口”用于检索会引入数字噪声。

处理：提交 RAG 前将具体编号泛化为“目标端口”，实时端口号仍只用于设备工具。

### 4. 模型回答详细度不能只靠 Prompt

用户明确要求“只回答端口号”或“结合文档详细分析”时，模型可能仍输出默认风格。

处理：Planner 之后增加确定性的回答偏好归一化，最终摘要由业务代码执行。

### 5. 设备任务工作流不能代替顶层对话路由

旧版把所有输入都尝试解释成设备命令，因此“你是谁”会落入“信息不足”，知识问题
也只能依附诊断链路。

处理：在统一 `DeviceCommand` 协议中增加聊天、知识、解释上一轮和范围外意图，
由 LangGraph 路由到独立节点；设备状态只约束设备分支，不影响普通聊天和知识问答。

### 6. 多轮记忆要保存证据，而不只是保存原始文本

只保留用户和助手文本时，“为什么”无法稳定解释上一轮结论，也容易把内部 action
名称暴露给用户。

处理：SQLite 会话同时保存脱敏摘要、业务意图、关键证据、知识来源和 Trace；
追问节点基于这些结构化事实生成可核验解释。

## 安全与真实性边界

- XDP MCP Server、底层工具和设备协议来自公司已有项目。
- 本项目实现 MCP 之上的 Agent 应用层与工程化能力。
- 真实设备操作仅针对本人授权的测试设备。
- `automatic` 是私有演示配置；公开示例默认 `approval`。
- 设备标识和私有 URL 只在 Git 忽略的 `.env`。
- 原始响应经过字段白名单后才进入工作流、API、UI 和审计。
- 当前验证的是单设备作品集闭环，不代表多租户、生产高可用、权限平台或全部设备
  型号已经完成。
